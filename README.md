# ⚡ Dissolved Gas Analysis (DGA) App

Streamlit-powered web app for transformer Dissolved Gas Analysis (DGA).
Includes Duval, Rogers, Key Gas, Trend analysis, Fleet dashboards, user login, and PDF reports.

## 🚀 Run
```
pip install -r requirements.txt
streamlit run app.py
```

Login with `master_user / master123` for testing.
